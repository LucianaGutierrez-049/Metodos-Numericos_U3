Cómo ingresar un ejercicio del examen

Despeja primero y′ y escribe solo f(x,y). Ejemplo: (x^2-y^2)/(x*y). Se admiten x o t como variable independiente y y como dependiente.

Usa * para multiplicar, ^ para potencias y punto para decimales. Funciones: sin, sen, cos, tan, exp, ln, log natural, sqrt, abs. Ángulos en radianes.

La solución exacta es opcional, se escribe en función de x y sirve para comparar. El sistema no despeja ni resuelve simbólicamente la EDO.

Sesión 14 · Despeje y solución exacta del problema
(y² − x²) dx + xy dy = 0
xy y′ = x² − y²
y′ = (x² − y²)/(xy)

Con u = y² y u′ = 2y y′ se obtiene u′ + (2/x)u = 2x. En x > 0, el factor integrante es x².

(x²u)′ = 2x³
x²u = x⁴/2 + C
y² = x²/2 + C/x²

Como y(1) = 2, C = 7/2 y se elige la rama positiva: y(x) = √(x²/2 + 7/(2x²)). El valor verdadero en 1.2 es 1.774980438.
