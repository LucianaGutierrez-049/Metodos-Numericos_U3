CALCULADORA DE INTEGRACIÓN PARA EXAMEN

Abre index.html en tu navegador. Funciona sin conexión.
En Visual Studio Code, abre esta carpeta y edita index.html, styles.css y app.js.

1. Ingresa una función con x o t: x^2+1, exp(x), 1/x, sin(x).
2. Ingresa límites a y b (b debe ser mayor que a). Puedes escribir pi, -pi o 1/2.
3. Ingresa n, entero entre 1 y 10000. n=1 aplica trapecio simple.
4. Opcional: ingresa el valor exacto de la integral para calcular errores.
5. Pulsa Resolver ejercicio. El desarrollo, gráfica y tabla se actualizan.

Usa * para multiplicar, ^ para potencias y punto para decimales.
Funciones: sin, sen, cos, tan, exp, ln, log (natural), sqrt, abs.
Constantes: pi y e. Ángulos en radianes.
No admite multiplicación implícita: escribe 2*x en lugar de 2x.

Incluye ejemplos precargados, tabla completa de puntos y pesos, sustitución en la fórmula, comparación de n y exportación CSV. Para guardar un PDF, pulsa Imprimir / guardar PDF y elige esa opción en tu navegador.

Sin valor exacto no se calcula el error real. Si el valor exacto es cero, el error porcentual no está definido. El valor exacto ingresado es responsabilidad del usuario: la aplicación no realiza integración simbólica.
Usa funciones continuas en el intervalo. Las comprobaciones numéricas no detectan necesariamente todas las singularidades. Los resultados son aproximaciones en punto flotante. Las unidades dependen de tu ejercicio.

SESIÓN 13 - SIMPSON 1/3
Selecciona el método antes de resolver. Simpson requiere n entero par >=2.
El ejemplo Consumo energético carga n=6 y una cota conservadora M=5.132.
M es opcional y debe acotar |f cuarta derivada| en todo el intervalo. No es el error real ni se calcula automáticamente.
La guía proporciona M=0.45, que no es válida para su función. La sección desplegable incluye el cálculo solicitado y la justificación de una cota válida.
El desarrollo manual se genera para cualquier función ingresada. La comparación de Simpson usa 2,4,6,12,24 y tu n. CSV incluye método y cota.
